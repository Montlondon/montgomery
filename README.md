# Montgomery OS 🧬

Sistema operacional pessoal de saúde de Montgomery Magalhães e família — um organismo vivo que une medicina convencional, MTC, Cabala, geometria sagrada, fitoterapia e longevidade.

*"Tudo é padrão. Tudo é proporção. Tudo é luz."*

## Status — Fase 1: Fundação ✅ (04/07/2026)

App standalone em `index.html` — HTML/JS puro, localStorage (offline-first), sem frameworks.

**Módulos vivos:**
- **Início** — visão do dia, alertas críticos sempre visíveis, últimos registros
- **Perfis da Família** — Montgomery e Esposa já semeados com histórico completo (alerta Fenitoína em vermelho permanente)
- **Sinais Vitais** — PA, FC, glicemia, SpO₂, peso, temperatura, com semáforo e gráficos de evolução
- **Protocolos** — medicamentos, suplementos, cogumelos (Lion's Mane, Reishi, Cordyceps, Chaga, Turkey Tail já semeados), fitoterápicos, florais — dose, ciclo, custo mensal, eficácia subjetiva
- **Exames** — marcadores laboratoriais com sugestões guiadas pelo histórico familiar (TFG, homocisteína, escore de cálcio...)
- **Backup** — exportar/importar JSON completo

**Segurança (padrão universal Montgomery):** Google OAuth via Supabase (montlondon@gmail.com) + biometria WebAuthn + fallback offline por senha local.
